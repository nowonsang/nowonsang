- 직원관리 앱(Nahago): 급여 데이터를 다루는 앱에 맞게 강한 본인확인(PIN · Face ID · FIDO · NICE)과 생체 간편 로그인을 함께 설계, 전자서명 인증서 개발
- 사내 React Native · Redux · Kotlin 교육과 테크톡 주도
